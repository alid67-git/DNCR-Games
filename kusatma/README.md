```bash

npm install
npm start
# http://localhost:3860
```

## Kurallar (kısa)

1. 5+5 taş konuşlandır
2. Turda **çizgi** veya **taş hareketi** (orthogonal; çizili kenar aşılamaz)
3. Kare kapanınca +10 / +50 (esir) + ekstra hamle; kombo ×1.5 / ×2
4. 2 taş kalınca Sigorta; kırmak 2 ShieldPoint
