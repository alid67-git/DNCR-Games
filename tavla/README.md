# Tavla

Klasik tavla (backgammon) — DNCR Games kabuğu.

## Modlar

1. Bilgisayara karşı (Kolay / Zor / Çok Zor)
2. Aynı cihazda iki kişi
3. İki telefonda / uzaktan — P2P oda kodu
4. Android hub — Bluetooth / yakında (~5 m)

## Geliştirme

```bash
cd tavla
npm test
npm start   # http://localhost:4178
```
