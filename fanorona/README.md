# Fanorona

Klasik **Fanorona** (Madagaskar) — yaklaşma / uzaklaşma ile alma, zincir hamleler.

- **Bilgisayara karşı** — Kolay / Zor / Çok Zor (çevrimdışı)
- **Aynı cihazda iki kişi** — ağ gerekmez
- **İki telefonda / uzaktan** — oda kodu, sunucusuz P2P
- **TR / EN**, skorlar, hamle vurgusu + SFX, DNCR hub çıkışı

## Çalıştır

```bash
npm install
npm start
```

Tarayıcı: `http://localhost:3871`

## Test

npm test
